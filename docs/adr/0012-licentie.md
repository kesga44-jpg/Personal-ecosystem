# ADR 0012 — Voorlopig geen licentie

- **Status:** geaccepteerd (2026-11-07), herbeoordeling gepland
- **Besluit-ID:** B-12

## Besluit

Geen `LICENSE`-bestand in de repo's. Publieke code zonder licentie betekent: alle rechten voorbehouden; anderen mogen de code bekijken maar niet hergebruiken.

## Herbeoordeling

Bij start van fase F6, of eerder als iemand wil bijdragen of hergebruiken. Opties dan: MIT, Apache-2.0, AGPL-3.0.

## Aandachtspunt

Afhankelijkheden blijven onder hun eigen licentie; de bronvermeldingsplichten (Open-Meteo CC BY 4.0, Open Food Facts ODbL) gelden ongeacht dit besluit.
